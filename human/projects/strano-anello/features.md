# Features

- Poll WordPress REST API per post e pagine.
- Parsing HTML commenti per ogni post.
- Stato corrente in SQLite per post/commenti.
- Eventi per insert/edit/delete.
- Snapshot Markdown runtime in `data/posts` e `data/comments`.
- Notifiche Telegram per eventi e failure/recovery.
- Diagnostica commenti bounded e deduplicata.
- CLI manutenzione DB: analyze, top-tables, growth, duplicates, anomalies, compact.
