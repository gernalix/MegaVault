# Features

- Dashboard Uptime Kuma su Oracle VM.
- Monitor push per backup, audit, automazioni e freeze analysis.
- Notifiche Telegram esistenti riusate.
- DB SQLite ispezionabile via SSH.
- Backup DB prima delle modifiche dirette.
- Monitor obsoleti disattivabili senza cancellare lo storico.
- Collegamento servizi locali tramite pusher con URL segreto in env file fuori da Git.
- Verifica push con HTTP 200 e controllo dello stato monitor in Kuma.
