# Windows Winget Daily Update Roadmap

## Ora
- Task giornaliero creato.
- Script e cartella log creati.
- Logging, timeout e continuazione su errore implementati.

## Prossimo
- Valutare se ri-registrare il task da PowerShell amministratore con `RunLevel Highest`.
- Decidere una retention per i log.

## Dopo
- Aggiungere cleanup automatico dei log vecchi se il volume cresce.
- Valutare una notifica finale solo se un aggiornamento fallisce.
