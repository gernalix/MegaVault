# megavault-project-exporter Features

- Live menu regenerated from MegaVault project indices on every run.
- One-number interactive project selection.
- Cached final ZIP keyed by selected project HEAD and MegaVault HEAD.
- Nested project and MegaVault `git archive` files with no Git repository directories.
- Local Mint clipboard path, optional SSH push to Mint, and headless scp/rsync command output.
- Size guardrail before transfer or clipboard operations.
